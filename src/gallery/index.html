使用方法

这样带走它

  1. 先看，再上手。组件进入视野后会循环播放一段操作演示。你直接点它、或用键盘进入时演示会停下，松手一会儿后从头再来。
  2. 复制提示词会带上组件的完整可运行代码和接入说明。粘到项目里的 AI 工具，补上插入位置即可。
  3. 下载代码文件会把同一个组件存成独立 HTML，自带深色/浅色主题令牌，打开就能看。
  4. 语言、主题、自动演示都在顶部按钮里切换，选择会在下次访问时保留。

交给 AI Agent 完成

安装 lucian-uxui 技能后，Claude Code、Codex 等编码 Agent 能在这个素材库里找到合适的组件，并搬进你的项目。
