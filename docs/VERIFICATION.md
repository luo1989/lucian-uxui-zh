## 6. 未验证 / 已知限制

- **未在真机 iOS Safari / Android Chrome 上测试**：移动端验证基于 Chrome 设备模拟（390×844，触控）。
- **未测试屏幕阅读器**：`aria-*` 属性保留上游实现，新增的收藏按钮已带 `aria-pressed` / `aria-label`，但未用 VoiceOver/TalkBack 实测。
- **中文版代码里的韩文注释会被移除**（与上游英文版策略一致）：注释里的设计说明不进代码；设计意图在中文提示词的说明与 `summary`/`hint` 中给出。
- **翻译为 AI 辅助 + 人工抽检**：已抽检 15+ 组件与全部界面文案；如发现个别不自然的措辞，可直接改 `src/i18n/zh/e/NNN.json` 后重新构建。
- **上游 `api/v1/` 仍只有 ko/en**：中文版没有生成 `api/v1/zh`（站点本身不依赖它）；如需给 Agent 技能提供中文数据，可按 `docs/SYNC-UPSTREAM.md` 扩展。
- **未做自定义域名**、未接入分析统计（无第三方脚本，符合纯静态、无追踪的取向）。
